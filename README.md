# Разработка LLM-приложений с LangGraph

Материалы курса о том, как строить приложения на основе больших языковых моделей: от первого HTTP-запроса к модели до агентов, которые сами вызывают инструменты.

Курс построен по принципу «снизу вверх». Сначала мы разбираемся, что происходит под капотом, и пишем всё руками на чистом Python и `requests`. Затем подключаем фреймворки, когда уже понятно, какую проблему они решают. Каждое занятие включает презентацию и Jupyter-ноутбук с практикой.

## Для кого этот курс

- Для разработчиков и аналитиков, которые хотят встроить LLM в свои продукты.
- Для тех, кто пробовал ChatGPT, но не понимает, как сделать из этого работающее приложение.
- Для тех, кто знаком с Python совсем немного: базовый синтаксис разбираем на практике.

## Программа

| Занятие | Тема | Материалы |
|---|---|---|
| [Занятие 1](lesson_1/) | Какие задачи решает ИИ: обзор возможностей и сценариев применения | презентация |
| [Занятие 2](lesson_2/) | Python с нуля до запроса к LLM: основы языка, классический NLP (pymorphy3, Natasha, TF-IDF), первый запрос к модели через API | презентация, ноутбук |
| [Занятие 3](lesson_3/) | От обёртки к агенту: системный промпт, история диалога, prompt-инъекции и защита, наивный RAG, tool calling вручную и анонс LangGraph | презентация, ноутбуки (GigaChat и AITunnel) |

*Программа будет пополняться по мере выхода новых занятий.*

## Как работать с материалами

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   ```
2. Откройте ноутбуки в Jupyter, VS Code или Google Colab.
3. Для запросов к моделям понадобится доступ к API. В ноутбуках третьего занятия есть два варианта:
   - **GigaChat** (бесплатный тариф Freemium);
   - **AITunnel** (агрегатор с доступом к разным моделям).

   Ключ API храните в переменных окружения или секретах Colab. Не коммитьте его в репозиторий.
